# ハリーの命紋診断

本質から、向いている仕事・働き方・金運を読み解く命紋独自の占いです。

[ハリーの命紋診断を使う](https://maison-orion.github.io/meimon/)

## 無料で読めること

- 内面の欲求、周りから見える姿、力が出る場面、疲れやすい場面を、4節の文章で読み解きます。
- 18歳の誕生日から現在までを年別の図でたどり、年を選ぶと詳しい説明が読めます。
- 今月を含む3か月は、結論、読み方、具体例を表示します。
- 「向いている仕事」「続けるか変えるか」「金運」の3テーマを選べます。16種類の本質別に職種の例、お金が出ていきやすい場面、見直し方を紹介します。

詳しい鑑定はLINEで案内する構成です。期間、料金、販売形式は未定で、現在アプリ内に決済はありません。LINEの接続先が未設定の場合は、受付開始の案内のみ表示します。

## 命紋の読み方

東洋の暦や干支の考え方を参考に、特徴の組み合わせと日常場面への読み替えを独自に設計しています。伝統的な暦そのものを新たに発明したものではありません。

基本の読み10種類と組み合わせ6種類から本質を読みます。年と月の干に対する生まれた日の干の関係を5つのテーマにまとめます。年別図の高さは独自の五行バランスに基づく運気の波で、実際の幸不幸や成功確率の点数ではありません。過去の実際の出来事や的中率を示すものではなく、ご自身の経験と照らし合わせる占いです。

年の境目は立春、月の境目は節入り。出生情報には現地の標準時を用い、真太陽時の補正はしません。出生時刻によって日が分かれる場合、流れは保留します。月初から節入り前は前区間の読みを表示します。暦の節入り時刻は国立天文台2026年の11件との照合で最大13.8分の差があり、境目の前後30分の出生は候補を並べます。人生の全対象年の暦は一次資料と照合済みではありません。

## 入力と保存

18歳以上の方が対象です。入力はブラウザー内で計算し、外部に送信しません。同じブラウザーに生年月日と結果が保存され、次回は入力し直さずに使えます。設定から削除でき、ブラウザーのデータ消去でも消えます。別の端末とは同期しません。プライベートモードや保存領域が使えない場合には保存できないことがあります。

シェアには生年月日や呼び名を含めません。LINEへのリンクにも出生情報や診断結果を自動で付けません。書体はGoogle Fontsから読み込みます。アクセス解析はありません。

## ファイルと確認

画面は `app.js`、暦は `engine.js`、判定は `method.js`、読みは `rules.js` と `essence.js`、適職は `careers.js`、金運は `money.js`、人生図は `life-flow.js`、保存は `storage.js` です。LINEの公式URLが確定したら `service.js` に設定します。

`python3 -m http.server` で起動し、`node tools/check-calendar.mjs` のように `tools/check-*.mjs` を実行して確認できます。実行時にAIや外部の鑑定サーバーは呼びません。

今後有料鑑定を提供する場合、認証、決済確認、内容の配信制御はサーバー側で別途実装します。この静的アプリの表示制限を購入権限の管理としては使いません。


性格の解説は詳しい部分を開いて読めます。16種類の本質から職種の例と選ぶ理由を紹介。18歳からの運気の波は独自の五行バランス指標で、実際の幸不幸や成功確率を測定した値ではありません。計算方法は図の説明から確認できます。

金運は収入や資産額の予測ではありません。持ち味の活かし方とお金との付き合い方を考える占いです。

## 命紋16タイプの名前

16タイプを「羅針盤の紋」「城の紋」「雷の紋」などの象徴名で表します。結果・見本・共有ページ・画像・PDFは同じ名前を表示し、具体的な特徴の文章も併記します。名前は判定IDに対応し、名前自体が性格や適職の正確性を証明するものではありません。
