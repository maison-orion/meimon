# 命紋診断（β版）

生年月日から、あなたの「性格の特徴」「合う環境」「苦手になりやすいこと」と、これから12か月のアドバイスを出す占いです。

[命紋診断を使う](https://maison-orion.github.io/meimon/)

- 無料・登録なし。質問は2つです。スマホのSafariやChromeでURLを開いて使えます。
- 仕事、恋愛・パートナー、家族・人間関係、お金・暮らし、自分自身から悩みを選べます。本質の判定は共通で、回答と月ごとのヒントを悩みに合わせます。
- 入力はブラウザーの中だけで計算し、どこにも送りません。タブを閉じると消えます。
- 診断後の感想や振り返りの入力は不要です。結果をそのまま読めます。
- 結果は画像で保存したり、X・Threads・LINEでシェアしたりできます。シェアに生年月日や呼び名は入りません。
- 占いの読みです。心理検査や適職検査ではありません。

## 読み方

四柱推命の一部を使う限定モデルです。生まれた日の干（日干）と、年・月・時の干の関係（通変星）を手がかりに、命紋の独自の規則で読みます。

- 基本の読み10種類と、二つの星がそろったときの組み合わせの読み6種類から、年・月・時の位置に沿って選びます。
- 12か月は、各月の干と日干の関係を5つのテーマに分けて読みます。年の読みは「1年を通して大切にしたいこと」として別に表示します。
- 月令、通根、蔵干、身旺身弱、格局、用神、大運は使っていないため、総合的な四柱推命の鑑定とは結果が異なることがあります。
- 読みの規則は研究中です。当たるかどうかは確かめている段階で、転職の成功や収入、出来事の的中は約束しません。

## 暦の計算

- 年の境目は立春、月の境目は十二の節入りです。太陽の視黄経から計算します。
- 日付の境目は現地の0時です。真太陽時の補正はしません。23時台の時の干は、その日の日干から数えます。
- 節入りの時刻を国立天文台の暦要項（2026年）の11件と照合し、差は最大13.8分でした。境目の前後30分に生まれた場合は候補を並べます。
- 生まれた時刻がわからない、または幅がある場合は、命式の候補ごとに読みます。すべての候補で一致した読みだけを確定として表示します。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` `styles.css` `app.js` | 画面 |
| `engine.js` | 暦と命式の計算 |
| `method.js` | 読みの選び方 |
| `rules.js` | 読みの文言 |
| `tools/check-calendar.mjs` | 暦の照合 |
| `tools/check-method.mjs` | 読みの選び方の確認 |
| `tools/check-contrast.mjs` | 文字と背景の読みやすさの確認 |

外部のライブラリやサーバーは使っていません。書体だけ Google Fonts から読み込みます。

手元で動かす場合は、このフォルダで `python3 -m http.server` を実行し、表示されたアドレスを開きます。確認は `node tools/check-calendar.mjs` のように実行します。
